# RetroHost Launchpad

tenho de criar uma landing page teste pra um site de uma empresa de hospedagem em nuvem, pensei em criar uma com o nome "mega brain host", quero um design minimalista, peguei como inspiração hostinger, hostgator, localweb, quero algo minimalista e bonito porem no final da pagina quero um botão que converta o site, quero uma animação de carregamento lenta quando clicar que nem como as paginas carregavam nos anos 2000, quero que o site todo mude e saia do minimalismo para o maximalismo, algo que fique parecido com sites dos anos 2000, estilo mais rustico e retrô, uma pegada frutiger aero, mas mantendo todas as mesmas informações e funções
