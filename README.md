Mega Brain Host

Um projeto de hospedagem em nuvem com uma proposta um pouco diferente.

O Mega Brain Host possui duas experiências visuais na mesma página:

Modern — uma interface simples, limpa e minimalista.
Retro — um modo inspirado nos sites dos anos 2000, com cores, animações e bastante personalidade.

A ideia é poder mudar completamente a aparência do site com um único botão, indo de uma interface moderna para uma experiência mais caótica e nostálgica da antiga internet.

Tecnologias
TypeScript
Node.js
Status
